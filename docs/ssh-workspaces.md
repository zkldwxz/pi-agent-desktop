# SSH 与多文件夹工作区

工作区管理可以从新对话的文件夹菜单，或工具面板的「文件 → 管理工作区文件夹」打开。

同一个工作区有一个主文件夹和若干附加文件夹。主文件夹决定默认命令目录与会话位置；附加文件夹出现在文件树中，`@` 文件搜索覆盖所有成员。agent 获得稳定的目录列表，使用绝对路径跨项目读取和修改文件。工作区成员保存在 `~/.pi/agent/desktop-workspaces.json`；任务运行期间不能修改成员。

SSH 连接支持密码、私钥文件与本机 SSH agent。连接前获取主机 SHA256 指纹，核对后认证。保存的连接资料位于 `~/.pi/agent/ssh-connections.json`，仅有主机、端口、用户名、私钥路径、指纹与上次连接的远程目录；密码、私钥内容与私钥口令不落盘。已保存主机的指纹发生改变时拒绝连接，需要删除旧连接并核对新指纹。重新选择已保存连接时会预填上次的远程目录，重连落回同一工作区锚点，历史会话保持可恢复。`ssh-connections.json` 或 `desktop-workspaces.json` 损坏时自动改名为 `.corrupt-<时间戳>.bak` 并按空配置继续，界面不会因此不可用。远端 `@` 文件搜索按目录层级并发请求，断连时明确报错而非返回空列表；远端 `git push` 使用 10 分钟超时。

连接进度展示：获取指纹、连接主机、认证、建立 SFTP 通道、检查项目目录、就绪。同一主机保存多条资料时，进度按本次选中的连接或正在认证的连接显示，断开后清除旧阶段。SSH 意外断开后远端文件与工具操作直接失败；通过管理页选择已保存连接重新认证即可恢复。

切换工作区文件夹时如有 agent、压缩、shell、后台回合或子智能体运行，会提示等待，不会静默中止任务。同工作区的新对话仍可保留正在运行的后台回合。删除当前 SSH 工作区先切回本机，再删除聊天与成员资料；丢失 SSH 工作区元数据时明确报错，不把会话锚点当成本机项目。删除已保存连接前，需要先删除引用它的工作区；单纯断开连接保留工作区和历史。

SSH 工作区隐藏本机文件管理器/IDE 的打开入口，远端文件使用应用文件浏览器查看。计划插件在本机生成文件，计划面板通过独立的 `readPlan()` 读取当前计划，不把本机路径传入 SSH 文件通道。

## 执行位置

当前采用本机 SDK + SSH/SFTP 工具模式。模型请求、pi runtime、配置、MCP 进程与聊天记录在本机；远端文件浏览、读写、编辑、搜索、Git、命令、PTY 在 SSH 主机。远端无需安装 Node 或 pi。远端支持 Linux/macOS 的 POSIX shell；`grep/find` 需要 `rg`，`powershell` 需要远端 `pwsh`。所有核心文件/命令工具（包含 PowerShell）一起覆盖，避免从 codemode 或工具搜索调用到本机内建工具。

远端聊天记录保存在本机 agent 目录的 `remote-workspaces/<稳定标识>` 会话锚点，通过该锚点恢复正确连接身份。附加远端目录必须来自同一个 SSH 连接。本机自定义扩展与 MCP 仍按本机配置执行；它们不自动搬到远端。

## 版本与磁盘占用

服务器上没有部署 pi 服务，不会下载服务版本，也不会生成旧版服务目录；更新桌面依赖即更新本机使用的 pi runtime。界面只展示实际发生的连接阶段。

如果后续切换为远端 pi 服务部署，必须实现以下生命周期，不能只增加一个下载按钮：

1. 探测运行中的服务版本与协议版本，兼容且版本一致时复用。
2. 在临时目录下载/上传新版本，向 UI 发布阶段、已传输字节、总字节、速度以及明确失败原因。
3. 校验完整性后切换到新版本，等待健康检查与协议握手成功。
4. 启动成功后删除旧版本目录和下载临时文件；整个部署最多保留当前版本与一个回滚版本，成功确认后按策略清理回滚版本。
5. 下载或启动失败保留当前可用版本；取消时终止上传/下载并删除临时目录。清理仅针对应用拥有的版本目录，不能扫描或删除用户项目。

当前版本没有远端服务安装器，这些是未来采用该架构时必须兑现的约束。

## 验证边界

`npm run test:workspace` 的 33 项回归启动临时真实 SSH 服务，走主机密钥握手、密码认证、SFTP 读写和远端 exec 通道，验证取消、失败码、成员持久化、跨项目路径、远端兄弟目录/遍历/符号链接越界、删除资料保护、缺失元数据拒绝本机回退、任务运行时的切换保护、远端 PTY 输出/重放、嵌套目录的层级并发搜索、连接资料记住远程目录、断连后搜索明确报错、损坏元数据隔离自愈，以及真实 pi SDK 中 read/PowerShell 的远端覆盖。浏览器预览验证管理界面，不会建立外部 SSH 连接。测试服务的文件系统和命令回复是受控 fixture，不能替代用户服务器的真实 shell/Git、SSH agent、私钥认证与网络断连端到端验证。
