# Model maker logos

Copied from baocode (`assets/model_icons/`, GPL-3.0 project). The glyphs come
from Iconify sets and keep their own licences — each `.svg` starts with a
comment naming its set, icon id and licence:

- Simple Icons — CC0-1.0
- theSVG — MIT
- Remix Icon — Apache-2.0

They are monochrome (`fill="currentColor"`) and drawn by `components/BrandLogo.tsx`;
which logo a model gets is decided by `lib/model-brand.ts` (a port of baocode's
`lib/models/model_brand.dart`).
